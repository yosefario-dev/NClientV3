Un client manga configurabile per Android.
Fork di NClientV2 di Dar9586, aggiornato per Android moderno.

Richiede Android 8.0 (API 26) e superiore, solo ARM a 64 bit.

Scegli le tue fonti nelle impostazioni. Nulla è configurato di default.

Funzionalità
 - Più fonti, ognuna con il proprio accesso
 - Sfoglia la pagina principale
 - Cerca per query o per tag
 - Includi o escludi tag
 - Sfoca o nascondi i tag esclusi
 - Scarica gallerie
 - Gallerie preferite, in locale o online, con liste dove la fonte le supporta
 - Blocco con PIN
 - Condividi gallerie
 - Apri nel browser
 - Apri i link supportati nell'app
 - Segnalibri
 - Cronologia

Novità nella V3
 - Design Material 3 / Material You
 - Correzione per Android 15+ (edge-to-edge, barra di stato)
 - Correzione del caricamento immagini CDN webp
 - Aggiornamento del sistema di build e delle dipendenze
 - Rimosso il report dei crash / tracciamento
 - Nessuna fonte è configurata finché non ne scegli una
