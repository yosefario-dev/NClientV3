A configurable manga client for Android.
Forked from NClientV2 by Dar9586, updated for modern Android.

Requires Android 8.0 (API 26) and above, 64-bit ARM only.

Choose your sources in Settings. Nothing is set up by default.

Features
 - Multiple sources, each with its own login
 - Browse main page
 - Search by query or tags
 - Include or exclude tags
 - Blur or hide excluded tags
 - Download galleries
 - Favorite galleries, locally or online, with lists where the source has them
 - PIN lock for privacy
 - Share galleries
 - Open in browser
 - Open supported links in the app
 - Bookmarks
 - History

What's new in V3
 - Material 3 / Material You design
 - Fixed for Android 15+ (edge-to-edge, status bar)
 - Fixed CDN webp image loading
 - Updated build system and dependencies
 - Removed crash reporting / tracking
 - No source is set up until you choose one
